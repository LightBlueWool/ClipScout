# ClipScout

AI-powered video search and clip extraction.

ClipScout lets you upload a video, describe what you're looking for in plain English, and automatically:

- 🎯 Find the best moments using AI
- ✅ Validate AI responses
- 📊 Rank clips
- 🎬 Extract MP4 clips automatically with FFmpeg

## Current Features

- Natural language clip search
- Runtime AI validation
- JSON export
- Automatic clip extraction
- TypeScript backend

## Tech Stack

- TypeScript
- Node.js
- Twelve Labs
- FFmpeg
